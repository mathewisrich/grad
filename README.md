# Kelly & Mathew · Graduation Gallery

A private, password-protected gallery for sharing graduation pictures.

- **Password gate** → funny fill-in-the-blank question
- **Landing page** → welcome + intro
- **Gallery** → 465 pictures, select any/all, download single or zip
- **Storage** → Cloudflare R2 (free 10 GB + free egress)
- **Hosting** → Vercel

## Tech

- Next.js 15 (App Router) + React 19
- Tailwind CSS
- Cloudflare R2 (S3-compatible storage)
- JSZip for client-side bulk downloads
- `sharp` for image compression

## Setup (already done, for reference)

1. Created Cloudflare R2 bucket `grad` with public dev URL.
2. Added CORS policy allowing GET/HEAD from any origin.
3. Created R2 API token with Object Read & Write on the `grad` bucket.
4. Filled `.env.local` (see `.env.example`).

## First-time upload

The original photos live in `113D3500/` (ignored by git).

```bash
npm install
npm run upload
```

This compresses each photo to:
- `full/<name>.jpg`  → 6000×4000 @ q85 (~1–1.5 MB, downloadable)
- `thumb/<name>.jpg` → 800px wide @ q80 (~60 KB, gallery grid)

Then it writes `lib/manifest.json` so the gallery knows what to display.

## Run locally

```bash
npm run dev
```

Open http://localhost:3000

## Deploy to Vercel

1. Push this repo to GitHub.
2. On vercel.com → New Project → import the GitHub repo.
3. In Vercel project settings, add the same env vars as `.env.local`:
   - `R2_ACCOUNT_ID`
   - `R2_ACCESS_KEY_ID`
   - `R2_SECRET_ACCESS_KEY`
   - `R2_BUCKET`
   - `R2_ENDPOINT`
   - `NEXT_PUBLIC_R2_PUBLIC_URL`
   - `SITE_PASSWORD`
4. Deploy.

After Vercel gives you the live URL, narrow the R2 CORS `AllowedOrigins`
from `["*"]` to just `["https://your-site.vercel.app"]` for extra safety.

## Password

The site password is whatever you put in `SITE_PASSWORD` (default `myshaylaa`).
The funny question shown on the gate is hard-coded in `components/PasswordGate.tsx`.
